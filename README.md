# 速算练习

一个轻量、响应式的中文口算练习网页。可选择打字或语音作答、练习难度与题目数量；练习结束后会显示答题统计。

## 本地运行

无需安装依赖。直接用浏览器打开 `index.html` 即可使用打字练习。语音识别需要浏览器支持 Web Speech API、麦克风权限及安全上下文（HTTPS 或 localhost）。

也可以在项目目录启动一个静态文件服务器：

```sh
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 发布到 GitHub Pages

在 GitHub 仓库的 **Settings → Pages** 中，将发布来源设为 `Deploy from a branch`，选择默认分支和 `/ (root)`，保存后即可通过 GitHub Pages 访问。

## 功能

- 打字输入或浏览器语音识别（中文普通话）
- 两位数、两/三位数混合、三位数加减练习
- 10、20、30 题或不限题数
- 即时反馈、进度、正确题数与正确率统计
- 手机与桌面自适应布局

语音识别能力取决于浏览器和系统支持情况；不支持时可使用打字作答。
