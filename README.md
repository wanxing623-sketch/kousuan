# 速算练习

打开就能用的加减法口算练习页。两位数、三位数都能练，可以按数字答题，也可以看着题直接说出答案。

没有框架、没有构建步骤、没有依赖，只有 `index.html`、`styles.css`、`app.js` 三个文件。

## 功能

- **两种作答方式**
  - 打字作答：题目下方的输入框，手机自动弹出数字键盘，回车或「确认答案」提交。
  - 语音作答：题目出现后直接说答案，识别成功自动进入下一题，不用点屏幕。
- **三种难度**：两位数 ± 两位数、两位数 ± 三位数、三位数 ± 三位数（加减随机，减法保证结果不小于 0）。
- **题量选择**：10 题、20 题、30 题或不限；不限时随时点「结束练习」。
- **练习中**：进度、答对题数、对错反馈，答错会给出正确答案。
- **结束后**：正确率、总用时、平均每题用时、错题回顾，以及该难度的最好成绩。
- **本地保存**：设置和最好成绩存在浏览器的 localStorage，不联网、不需要账号。
- **移动端优先**：底部输入区单手可达、点击区域不小于 44px、适配刘海屏安全区、尊重「减少动态效果」系统设置。

## 语音作答说明

语音识别用浏览器自带的 Web Speech API（`SpeechRecognition` / `webkitSpeechRecognition`），不需要下载模型或额外服务：

- Chrome、Edge、Safari 可用；Firefox 暂不支持，会自动禁用语音选项并提示。
- 需要麦克风权限，并且页面必须在 **HTTPS 或 localhost** 下打开。
- 识别结果支持中文数字和阿拉伯数字，例如「八十三」「一百零五」「83」「一零五」。
- 能容忍常见的识别偏差：
  - 同音字，例如「四」被听成「是」「寺」「事」；
  - 带口语或多余字，例如「答案是 47」「这个数是 47 吧」「嗯 47」；
  - 口语省字，例如「两百五」按 250、「一千二」按 1200。
- 没有听到数字时会提示再说一次；连续三轮都没有声音会暂停收音，点「继续收音」即可。
- 点麦克风可随时暂停收音；切到别的标签页时自动放下麦克风，这段时间也不计入用时。
- Safari 在首次授权之后，可能要求再点一下才继续收音，页面会给出「继续收音」按钮。
- 在嵌入式预览窗口里，浏览器可能直接拦截麦克风。此时页面会给出「重新打开麦克风」和「在新窗口打开」，也可以一键改用打字作答。

## 操作快捷键

| 按键 | 作用 |
| --- | --- |
| Enter | 提交答案 / 跳过反馈直接下一题 |
| Esc | 结束本组，查看成绩 |

## 兼容性

- 建议 iOS / iPadOS 12 以上、Chrome / Edge / Safari 近几年的版本。
- 脚本语法已避开较新的写法，iOS 10.3 起应该能跑；更旧的系统上，页面顶部会直接显示「脚本没有运行，点这里重新加载」，而不是让你对着点不动的按钮猜。
- 布局关键间距不再依赖 flex 的 `gap`（Safari 14.5 之前不支持），旧 iPad 上不会挤在一起。

## 本地运行

直接用浏览器打开 `index.html` 即可。语音识别建议用本地服务器：

```sh
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 发布到 GitHub Pages

> 发布前把 `index.html` 里 `styles.css?v=` 和 `app.js?v=` 的版本号改一下（例如 `20261119b`）。
> GitHub Pages 的 HTML 会缓存 10 分钟，带版本号可以避免用户遇到「新页面配旧脚本」的错乱状态；
> `app.js` 开头还有一层自检，发现页面结构对不上时会自动重新取一次页面。

在仓库 **Settings → Pages** 中把发布来源设为 `Deploy from a branch`，选择默认分支和 `/ (root)`。仓库里的 `.github/workflows/pages.yml` 也会在推送到 `main` 时自动部署。
