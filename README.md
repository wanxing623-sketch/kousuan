# 速算练习

一个轻量、响应式的中文口算练习网页：打字或语音作答，题目随机生成，练完有计时统计和错题重练。无依赖、无构建，单个静态站点即可部署到 GitHub Pages。

## 功能

- 两种作答方式：打字输入、语音说出答案（自动聆听，逐题衔接）
- 三档难度：两位数 ± 两位数、两位数 ± 三位数、三位数 ± 三位数（开局自选）
- 题量 10 / 20 / 30 / 不限；答错后停留看正确答案，可跳题
- 计时统计：总用时、平均每题、最高连对、历史最佳（保存在本机）
- 错题重练：答错或跳过的题可一键重练
- 设置记忆、深色模式、移动端优先、练习时屏幕常亮

## 本地运行

直接用浏览器打开 `index.html` 即可使用打字模式。语音模式需要安全上下文（HTTPS 或 localhost）与麦克风权限：

```sh
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 语音识别：为什么用 Web Speech API

调研了几个开源语音识别方案（见下表），本项目选择浏览器内置的 Web Speech API（`SpeechRecognition`）：零依赖、零 API Key、中文识别开箱即用，适合静态站点。

| 方案 | 特点 | 未采用的原因 |
|---|---|---|
| Web Speech API（本项目） | 浏览器内置，中文识别好，免费 | 依赖浏览器支持（Chrome 最好），需联网 |
| Vosk（alphacep/vosk-api，Apache-2.0） | 离线、实时、模型小 | 中文模型需下载数十 MB，移动端加载慢 |
| Whisper（openai/whisper，MIT）/ whisper.cpp / transformers.js | 准确率高、99 种语言 | 浏览器端运行 tiny 模型也要约 75MB，手机上慢且耗电 |
| AssemblyAI 等云 API（如 GitHub 上的 VoiceMath 项目） | 实时识别效果好 | 需要 API Key 与付费，不适合免费静态站点 |

语音会由浏览器厂商的识别服务处理（非完全离线）；介意隐私或需要离线时，可切换 Vosk。浏览器不支持时会自动提示改用打字作答。

## 部署到 GitHub Pages

仓库自带 `.github/workflows/pages.yml`，推送到 `main` 后自动发布（发布环境只允许 `main` 部署，功能分支的推送不会触发发布）。首次使用请在 GitHub 仓库 **Settings → Pages** 中把发布来源设为 **GitHub Actions**。

## 目录

- `index.html` — 页面结构
- `app.js` — 题目生成、计时、语音识别与中文数字解析
- `styles.css` — 样式（移动端优先，支持深色模式）
- `fonts/` — 按页面用字裁剪的 Noto Sans SC（SIL OFL 1.1，许可证见 `fonts/OFL.txt`），两个字重合计约 190KB，离线可用（字体加载失败时自动回落到系统字体）

## 一些设计取舍

- 题目只做不退位到负数的加减法，减法保证被减数不小于减数，避免出现负数答案。
- 答错后不自动跳题：停在这一题显示正确答案，确认后按回车或点「下一题」继续。
- 计时只统计真正在答题的时间：答错后停下来看答案时暂停，平均每题更有参考意义。
- 触控目标不小于 44px，输入框字号 20px（避免 iOS Safari 聚焦时自动放大），练习时申请屏幕常亮，答对/答错有轻震动反馈。
- 语音模式连续三次没听到数字会暂停聆听，避免一直占着麦克风；切到后台会自动暂停计时并放下麦克风。
- 浏览器不支持语音识别时，语音模式直接露出输入框，不用再多点一次。
